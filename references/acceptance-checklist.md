# RZCN 验收清单

## 申请事实

- [ ] 软件全称、简称、版本号已确认。
- [ ] 著作权人与身份证明一致。
- [ ] 开发方式、完成日期、权利取得方式有真实依据。
- [ ] 发表状态和首次发表信息已确认。
- [ ] 申请表、说明书、源码页眉和 PDF 元数据使用同一版本。

## 程序鉴别材料

- [ ] 使用独立源码副本，正式项目源码未修改。
- [ ] 文件清单完整，未加入无关文件。
- [ ] 总文件数、总行数和语言统计可复现。
- [ ] 超过 60 页时使用连续前 30 页和连续后 30 页。
- [ ] 未超过 60 页时提交完整源码，不添加虚假填充行。
- [ ] 每页至少 50 条源码显示行。
- [ ] 页眉、页码、页脚连续。
- [ ] 长行自动续行，无截断、覆盖或越界。
- [ ] 页面文本与选定源码逐行匹配。
- [ ] 副本文件行数与整理前一致，或已获准改变统计口径。
- [ ] 代码语法/格式检查通过。

## 文档鉴别材料

- [ ] 使用一种完整、真实的说明书或技术文档。
- [ ] 文档不足 60 页时整套提交。
- [ ] 文档达到 60 页时提交连续前 30 页和后 30 页。
- [ ] 每页至少 30 条正文行。
- [ ] 末页不足 30 行时使用真实附录或补充章节，不重复灌水。
- [ ] 目录、页码、章节编号与最终 PDF 一致。
- [ ] 文档描述与源码事实、配额、时限、数据字段一致。
- [ ] 无旧版本名称、旧版本号和失效部署信息。

## 脱敏

- [ ] 源码副本无真实 IP、域名、SSH、部署路径、数据库凭据和私钥。
- [ ] PDF 提取文本无敏感值。
- [ ] PDF 元数据无内部主机名、真实邮箱或临时路径。
- [ ] 文件路径、提交说明和校验文件不含敏感值。
- [ ] 敏感扫描结果已记录，未把零命中表述为法律结论。

## 交付

- [ ] `00_提交文件` 只包含要求上传的文件。
- [ ] 两份 PDF 可正常打开并逐页浏览。
- [ ] 记录 SHA-256。
- [ ] 记录未验证项和申请人待确认事实。
- [ ] 不擅自提交、签章、上传或对外发布。
